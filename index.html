Off-road bump profile, left and right tyre, 0 to 5 s

You can also paste a MotionSolve function into a tyre's function box and the graph follows it. Each tyre has its own table. An obstacle is either a smooth ramp (rise, top, fall) or a standard sine bump, which is a half sine wave. Both tyres use the one vehicle speed set below, and the time on an obstacle is its length divided by that speed. Use a negative height for a pothole. Drag the dots on a graph to edit an obstacle: left and right changes its timing or length, up and down changes its height.
